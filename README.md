## Featured Project

### [E-commerce Customer Retention Analytics Pipeline](https://github.com/ayrtonbezerra/ecommerce-customer-retention-pipeline)

An end-to-end analytics engineering project that automates customer retention monitoring using synthetic e-commerce data.

The pipeline features incremental and idempotent ingestion into PostgreSQL, analytical modeling with dbt, workflow orchestration with Apache Airflow, automated testing, and CI with GitHub Actions. It generates weekly retention reports to identify churned and at-risk customers.
