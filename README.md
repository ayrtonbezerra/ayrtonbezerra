## 🚀 Featured Project

### [E-commerce Customer Retention Analytics Pipeline](https://github.com/ayrtonbezerra/ecommerce-customer-retention-pipeline)

![CI](https://github.com/ayrtonbezerra/ecommerce-customer-retention-pipeline/actions/workflows/ci.yml/badge.svg)

An end-to-end analytics engineering project that automates customer retention monitoring using synthetic e-commerce data.

**Key engineering features:**
- Incremental and idempotent data ingestion into PostgreSQL
- Analytical modeling and data quality testing with dbt
- Workflow orchestration with Apache Airflow
- Automated testing and CI with GitHub Actions
- Weekly retention reports identifying churned and at-risk customers
